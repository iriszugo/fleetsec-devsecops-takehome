# Security Policy

## Supported Versions

This repository is a technical assessment project. Security fixes are applied to the latest version available in the `main` branch.

## Reporting a Vulnerability

Do not disclose vulnerabilities through public issues.

Report security findings through the official FleetSec technical assessment communication channel provided by the evaluation team. Do not disclose vulnerabilities publicly.

Include:

- Affected component
- Vulnerability description
- Reproduction steps
- Security impact
- Suggested remediation
- Supporting evidence

## Response Process

1. The finding is reviewed and classified.
2. The impact and affected assets are validated.
3. A remediation plan is defined.
4. The correction is verified with the applicable security tools.
5. The result is documented in the repository evidence.

## Sensitive Information

Never include real credentials, tokens, personal data, AWS access keys, private keys or production information in reports, commits, issues or pull requests.
