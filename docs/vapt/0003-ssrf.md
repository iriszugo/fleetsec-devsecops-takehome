# Server-Side Request Forgery (SSRF) (CWE-918)

## 1. Executive Summary

| Field | Value |
|-------|-------|
| Vulnerability | Server-Side Request Forgery (SSRF) |
| CWE | CWE-918 |
| OWASP Top 10 | A10:2021 – Server-Side Request Forgery |
| Severity | High |
| Status | Mitigated |

---

## 2. Description

This laboratory demonstrates a Server-Side Request Forgery (SSRF) vulnerability where user-controlled URLs are used to perform outbound HTTP requests. Without validation, an attacker could abuse the application to access internal services, cloud metadata endpoints, or other protected resources.

The secure implementation validates destinations before making outbound requests and blocks localhost, private IP ranges, and other non-authorized targets.

---

## 3. Vulnerable Scenario

Example vulnerable implementation:

```javascript
await axios.get(req.body.url);
```

The destination URL is entirely controlled by the client.

---

## 4. Secure Implementation

The secure implementation validates every outbound request before it is executed.

Security controls include:

- Allowlist validation.
- Blocking localhost.
- Blocking private IP ranges.
- Rejecting metadata service addresses.
- Timeout enforcement.

## 8. Mitigation

Implemented controls:

- URL validation.
- Destination allowlist.
- Localhost protection.
- Private network protection.
- Metadata endpoint protection.
- Automated regression testing.
